BIRYANI

Ingredients:

  • Chicken
  • Basmati rice
  • Chicken masala
  • onions
  • oil
  • ghee
  • corriender
  • salt
  • chill powder
  • ginger parlic paste
  • lemon jucie
  • mint leaves

Instructions:

  1. Wash and soak the basmati rice for 20min
  2. marniate the chicken with curd,ginger gralic paste,spices,mint,corriender
  3. Fry the onions till it turns into golden colour
  4. in same pan add whole spieces, green chilies and cook the chicken till oil separes and its almost done
  5. layer the half cooked rice on the chicken
  6. on the top with fried onions, mint , corriender, ghee
  7. cover it tightly and cook on the low flame for 20min
  8. rest it for 5 min and mix gently
  9. And finally biryani is ready
  10. serve hot and enjoy your meal

HTML:
HTML (HyperText Markup Language) is the standard language used to create and structure web pages. It organizes content using tags and works with CSS and JavaScript to build modern websites.
Paired Tags and Unpaired Tags:
Paired tags in HTML have both an opening and a closing tag, They are used to wrap content and define its structure. Unpaired tags have only a single tag and do not need a closing tag, They are mainly used for inserting elements like line breaks and images.
Elements:
HTML elements are the building blocks of a web page and consist of a start tag, content, and an end tag. The main types of HTML elements are block-level elements which take full width, and inline elements which take only required space.
Lists
HTML lists are used to group related items together in a structured way. The main types of lists are Ordered Lists (numbered), Unordered Lists (bulleted), and Description Lists (term and description).
